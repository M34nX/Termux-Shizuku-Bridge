# عیب‌یابی

## ابزار خط فرمان پایتون

از این فرمان‌ها شروع کنید:

~~~bash
tsb doctor
tsb report
~~~

به‌روز بودن Termux، نصب Python 3.10 یا جدیدتر، فعال بودن Shizuku، مجاز بودن Termux در Shizuku و خروجی‌گرفتن از ابزار رسمی rish و فایل DEX همراه را بررسی کنید.

### rish پیدا نمی‌شود
۱. راهنمای یکپارچه‌سازی ترمینال در Shizuku را باز کنید.
۲. ابزار رسمی rish را برای Termux خروجی بگیرید.
۳. آن را در مسیر ~/rish یا یکی از پوشه‌های PATH قرار دهید.
۴. اگر مسیر دیگری دارد، متغیر TSB_RISH را روی مسیر دقیق آن تنظیم کنید.

ابزار را از منبع نامطمئن دریافت نکنید.

### فایل DEX همراه پیدا نمی‌شود

ابزار رسمی rish به فایل rish_shizuku.dex نیاز دارد.
- هر دو فایل را طبق راهنمای نسخهٔ نصب‌شدهٔ Shizuku دوباره خروجی بگیرید.
- در صورت امکان فایل DEX را کنار rish قرار دهید.
- برای مسیر سفارشی از TSB_RISH_DEX استفاده کنید.
- در اندروید ۱۴ به بالا از راهنمای فعلی Shizuku پیروی کنید؛ اجرای DEX قابل‌نوشتن از طریق app_process محدود شده است.

### Shizuku متوقف است یا Termux مجوز ندارد

در دستگاه‌های بدون روت ممکن است سرویس Shizuku پس از راه‌اندازی مجدد دستگاه به شروع دوباره نیاز داشته باشد. طبق راهنمای رسمی Shizuku عمل کنید و سپس Termux را صریحاً در فهرست برنامه‌های مجاز کنید. TSB سرویس را شروع نمی‌کند و مجوزی اعطا نمی‌کند.

## اپلیکیشن اندروید

### شیزوکو در دسترس نیست
- نصب بودن Shizuku و فعال بودن سرویس آن را بررسی کنید.
- TSB Mobile را دوباره باز کنید یا دکمهٔ به‌روزرسانی را بزنید.
- وجود ورودی ShizukuProvider در Manifest را طبق راهنمای رسمی بررسی کنید.
- دسترسی Binder اثبات‌کنندهٔ سالم بودن پل rish نیست.

### ترموکس شناسایی نمی‌شود

برنامهٔ رسمی Termux را نصب کنید. بررسی دیده‌شدن بسته با نام com.termux انجام می‌شود.

### ساخت اپ اندروید شکست می‌خورد
- از JDK 17 استفاده کنید.
- Android SDK Platform 35 و Build Tools 35.0.0 را نصب کنید.
- Gradle 8.9 و Android Gradle Plugin 8.7.3 را به کار ببرید.
- حداقل SDK برنامه API 24 است؛ کتابخانهٔ انتخاب‌شدهٔ Shizuku همین حداقل را اعلام می‌کند.
- هدف کامپایل Java و Kotlin هر دو باید JVM 17 باشند.

## حریم خصوصی گزارش

CLI مسیرهای محلی و شناسه‌های غیرپیش‌فرض برنامه را به‌طور پیش‌فرض پالایش می‌کند. گزارش اپ شامل مدل دستگاه و وضعیت بسته‌ها و Binder است. پیش از اشتراک‌گذاری آن را بررسی کنید.
