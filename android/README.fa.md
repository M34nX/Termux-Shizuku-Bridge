# TSB Mobile

اپلیکیشن همراه بومی اندروید برای پروژهٔ Termux-Shizuku-Bridge که با Kotlin و Jetpack Compose ساخته شده است.

## امکانات نسخهٔ ۰٫۲٫۰

- تغییر زبان فارسی و انگلیسی و ذخیرهٔ انتخاب کاربر به‌صورت محلی.
- تشخیص نصب بودن بسته‌های Termux و Shizuku.
- استفاده از API و ShizukuProvider رسمی برای بررسی دسترسی Binder.
- نمایش نسخهٔ اندروید، سطح SDK، سازنده و مدل دستگاه.
- راهنمای راه‌اندازی و میانبر بازکردن Termux یا Shizuku.
- کپی گزارش تشخیصی محلی پس از اقدام کاربر.

## محدودیت‌های مهم

این نسخه وجود rish، فایل DEX همراه آن، UID راه‌دور یا اجرای فرمان از راه دور را تأیید نمی‌کند. در دسترس بودن Binder شیزوکو اثبات نمی‌کند که کل پل Termux → rish → Shizuku آماده است.

اپ از Shizuku مجوز ممتاز درخواست نمی‌کند، فرمان shell اجرا نمی‌کند، UserService راه‌اندازی نمی‌کند، تنظیمات اندروید را تغییر نمی‌دهد و گزارشی بارگذاری نمی‌کند. مجوز INTERNET نیز در Manifest وجود ندارد.

## پیش‌نیازهای ساخت

- JDK 17
- Android SDK Platform 35 و Build Tools 35.0.0
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- حداقل Android API 24

پوشهٔ android/ را در Android Studio باز کنید یا از همین پوشه اجرا کنید:

~~~bash
gradle :app:assembleDebug
~~~

فایل APK آزمایشی در مسیر زیر ساخته می‌شود:

~~~text
app/build/outputs/apk/debug/app-debug.apk
~~~

GitHub Actions همین فرایند ساخت را اجرا می‌کند. در صورت موفقیت ساخت روی شاخهٔ بتای پروژه، workflow فایل APK را به‌عنوان artifact ذخیره و یک پیش‌انتشار GitHub ایجاد می‌کند.

## نصب و آزمایش

فقط APKای را نصب کنید که کد آن را بررسی کرده و به آن اعتماد دارید. پس از نصب، Shizuku را طبق راهنمای رسمی راه‌اندازی کنید. TSB Mobile هنگام بازگشت به برنامه یا فشردن دکمهٔ به‌روزرسانی، وضعیت محلی را دوباره بررسی می‌کند.

آزمایش روی دستگاه واقعی لازم است؛ CI فقط ساخت و بسته‌بندی پروژهٔ اندروید را بررسی می‌کند.
